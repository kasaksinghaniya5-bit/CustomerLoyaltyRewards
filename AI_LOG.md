# AI-Assisted Development Log

## 1. Introduction

This document records the use of Artificial Intelligence (AI) tools during the development of the Customer Loyalty Rewards System.

AI assistance is being used to support requirement analysis, project planning, architecture design, coding, debugging, documentation and testing.

The developer remains responsible for reviewing suggestions, making decisions, testing implementations and correcting errors.

## 2. AI Usage

AI assistance may be used for:

- Understanding project requirements.
- Identifying functional and technical requirements.
- Planning the system architecture.
- Designing database models and API endpoints.
- Generating and explaining code.
- Identifying and debugging errors.
- Preparing project documentation.
- Creating and reviewing test cases.
- Improving security and data validation.

## 3. Developer's Contribution

The developer is responsible for:

- Defining project requirements and expected behaviour.
- Making decisions about application features.
- Reviewing AI-generated suggestions.
- Running commands and implementing code.
- Testing application functionality.
- Identifying incorrect or incomplete suggestions.
- Reporting problems and verifying corrections.
- Maintaining the GitHub repository and project documentation.

## 4. AI Interaction Records

Actual interactions will be added throughout development.

Each record will include:

- Developer's original suggestion or question.
- Relevant AI assistant response.
- Implementation or decision outcome.

## 5. AI Mistakes and Corrections

At least two actual instances of incorrect or incomplete AI suggestions will be documented during development.

For each instance, the record will include:

1. What the AI suggested incorrectly.
2. How the developer identified the issue.
3. What correction was made.
4. The final verified outcome.

Only genuine mistakes and actual corrections will be recorded.

## 6. Conclusion

AI is being used as a development assistant rather than as a replacement for developer involvement.

All important requirements, generated code and suggested solutions will be reviewed and tested before being accepted into the project.
